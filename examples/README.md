# Examples

Examples show how GSE reasoning changes the shape of a task without turning examples into normative rules.

- [`bug-fix.md`](bug-fix.md) — a small but user-visible defect handled by one root GSE with focused evidence and a real user-path check.
- [`dynamic-collaboration.md`](dynamic-collaboration.md) — several software requests are coordinated by one root owner and delegated only where independence makes parallel work worthwhile.
- [`context-recovery.md`](context-recovery.md) — a long-running task survives context loss by preserving outcome, evidence, stable identifiers, blockers, and the next concrete goal.
