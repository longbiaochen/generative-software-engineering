## 中文

### 1/3

1/3 我提出了「生成式软件工程」（GSE）：一个根 Agent 对软件意图端到端负责，贯穿实现、验证、交付和维护。

Intent → Executable / Maintainable Software Entity

### 2/3

2/3 当独立工作的收益足以抵偿协调成本时，再委派子 Agent；最终责任仍由根 Agent 承担。用证据证明完成，只为当前需求和已证实的风险增加工程复杂度。

### 3/3

## English

### 1/3

1/3 Introducing Generative Software Engineering (GSE): one root agent owns a software intent through implementation, verification, delivery, and maintenance.

Intent → Executable / Maintainable Software Entity

### 2/3

2/3 Delegate when independent work earns its coordination cost. Keep responsibility with the root agent. Claim completion with evidence. Add complexity only for current requirements and demonstrated risks.

### 3/3

3/3 GSE v0.1 is an open research method whose effectiveness remains to be tested. Explore the specification, examples, and benchmark protocol. Critiques and reproducible comparisons are welcome.
