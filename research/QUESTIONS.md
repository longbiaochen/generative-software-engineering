# Open research questions

1. At what task size and dependency structure does dynamic delegation outperform a single root agent after total coordination cost is included?
2. Which evidence-selection policies best predict real user-path success while minimizing redundant testing?
3. How much do explicit recoverable outcome fields improve long-running task completion across context compaction or handoff?
4. Can minimal-sufficient-engineering rules measurably reduce state-space growth, maintenance burden, and agent rework without increasing escaped defects?
5. When does independent evaluation materially reduce self-verification bias, and when is it unnecessary overhead?
6. Which harness primitives most strongly affect end-to-end completion: context quality, isolation, deterministic identity, tool breadth, persistent evidence, or agent coordination?
7. How should GSE benchmarks measure maintainability of generated software beyond immediate task success?
