# Contributing

Contributions should improve the precision, explanatory power, falsifiability, or practical usefulness of GSE.

For normative changes, describe the concrete failure or research evidence motivating the change, identify the invariant being added or changed, and update the single owning document. Avoid duplicating the same rule across multiple files.

For examples, state the intent, baseline, outcome contract, delegation decision, implementation result, evidence, and remaining limitations. Examples demonstrate the method; they do not create normative rules.

For research, separate hypotheses from observed results. Record enough experimental context to reproduce or challenge the result, including task set, model/runtime configuration, tool availability, agent organization, token/cost accounting, wall-clock time, and quality criteria.

Before committing, check Markdown links, inspect the final diff, and keep the repository free of secrets, credentials, private data, and product-specific operational details.

## Public communication languages

GitHub README content and X communications for this project must be available in both Chinese and English. Each version must be complete and independently readable; a short summary does not replace the other language. Keep corresponding claims, version information, and links aligned when updating either language.

Maintain the English README in [`README.md`](README.md) and the Chinese README in [`README.zh-CN.md`](README.zh-CN.md), with visible reciprocal language links. Prepare paired Chinese and English X posts or threads; the launch drafts live in [`communications/x-launch.md`](communications/x-launch.md).

本项目的 GitHub README 和 X 平台文案必须同时提供中文与英文。每个版本都应完整、可独立阅读，不能用简短摘要代替另一种语言。更新任一语言时，应同步对应的主张、版本信息和链接。

英文 README 位于 [`README.md`](README.md)，中文 README 位于 [`README.zh-CN.md`](README.zh-CN.md)，两者在顶部互相提供语言切换链接。X 帖子或推文串应准备对应的中英文版本，发布草稿见 [`communications/x-launch.md`](communications/x-launch.md)。

## Publication receipts

After each public post, include actual screenshots of the published page and its permanent link in the final reply to Longbiao. Embed the screenshots directly in Markdown so they are visible without opening another file; show the publishing account, relevant content, and publication time, covering both languages when applicable. Archive the captures with that day's publication record. A draft, recreated image, or text-only completion report does not count as the publishing scene.

每次发文后，在给龙彪的最终回复中直接展示已发布页面的真实截图，并附永久链接；截图应能核对账号、正文和发布时间，双语内容应覆盖中英文。截图与当天发文记录一起归档，不能用草稿、重绘图片或仅文字报完成代替发布现场。
